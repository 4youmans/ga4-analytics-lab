# Состояние проекта по темам ОП.03

Автор: Паюсов Семён · РПО 2\25. Проверка 21.10.2026.

Источник: https://algorthimization-course-vvodnoe.vercel.app/op03-informacionnye-tehnologii/index.html

Все материалы находятся в одном репозитории 4youmans/ga4-analytics-lab.

| Тема | Выполнено | Остаётся |
|---|---|---|
| 1: путь данных | Собственный путь ссылки к заявке реализован | Отчёт с реальным Network/Payload |
| 2: воронка, 3: UTM | Исследованы пять источников и два кейса; lesson_02. Собственные метки проходят до формы и Sheets | Проверки настроек ресурса перечислены ниже |
| 4: GA4 | Свой поток, URL, Enhanced Measurement проверены | Часовой пояс, валюта, бизнес-цели ресурса |
| 5: Vercel и Google Tag | Код опубликован, Production-форма проверена; lesson_03 | Кадр обнаружения тега, подробные обработанные отчёты |
| 6: события | DebugView, параметры utm_visit/cta_click, два определения, generate_lead ключевое; lesson_04 | Проверка всех четырёх событий вне отладки |
| 7: заявки | Три подтверждённых тестовых ID, защита от дублей; lesson_05 | Дополнительные кадры проверки статусов и подсветки |
| 8: очистка | Google Таблица, ARRAYFORMULA, v1 → v2, 8 строк, CSV/XLSX; lesson_06 | Кадры фильтра статусов и формул |
| 9: ManyChat | Материал и UTM, Instagram «Автор», опубликован пост, канал подключён и сценарий LIVE; lesson_07 | Полный тест со второго аккаунта (у владельца его нет) |
| 10: Explore | Закрытая воронка 7 → 1 → 1 → 1 и путь после CTA; lesson_08 | Free form, обратный путь, сегменты и выгрузки |
| 10.2: DataLens | Яндекс ID и DataLens созданы, пробный период без платёжного аккаунта | Проверка сохранения подключения, датасет без контактов и дашборд |

Отчёты фиксируют выполненные действия и открытые проверки. Учебные CSV не выдаются за реальные заявки сайта. generate_lead — попытка отправки, Actual Leads — уникальные request_id в Sheets.
